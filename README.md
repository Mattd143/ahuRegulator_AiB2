# Projekt 2 Autmatyka inteligentnych budynków
Dublinowski Mateusz 193182, Cielecki Krzysztof 193203, Grupa 7

Projekt symulacji centrali klimatyzacyjnej z krzyżowym wymiennikiem ciepła oraz nagrzewnicą wodną (grupa 7) w formie obiektu .net. Program zawiera:
- Kaskadową regulację temperatury z możliwością ustalenia ograniczenia dolnego i górnego temperatury nawiewu.
- Zabezpieczenie p-zamr. nagrzewnicy wodnej.
- Zabezpieczenie p-zamr. układu odzysku ciepła.
- Zabezpieczenie urwania paska wentylatora (uruchamiane przez presostat wentylatora nawiewu)
- Antiwindup regulatorów PI.
- Opóźnienia załączania wentylatorów, nagrzewnicy wodnej i wyłączania wentylatorów.
- Możliwość zmiany parametrów regulatorów, opóźnień centrali oraz ograniczeń z poziomu formularza fmParametry
